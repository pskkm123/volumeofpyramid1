Key reasoning:

3 identical pyramids make up the cube, so:

3 × (volume of pyramid) = volume of cube = base × height
volume of pyramid = 13 × base × height

💡 Using Cavalieri's principle, we can go further: as long as the base area and height are the same, all pyramids and cones have the same volume — so this ⅓ holds for any pyramid, not just the one cut from a cube.
